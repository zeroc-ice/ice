- Passing `null` to the setter of an optional data member now clears the member (as if you called `clearFoo()`).
  Previously, passing `null` still marked the member as 'set', causing the generated `optionalFoo()` getter to throw.
  For string, sequence, and dictionary members this also changes what the peer receives: such a member was previously
  marshaled as an empty value, and is now not marshaled at all.
