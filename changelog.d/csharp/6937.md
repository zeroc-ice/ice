- A `<SliceCompile Update="...">` or `<SliceCompile Remove="...">` in a project file now applies to the `.ice` files
  that ZeroC.Ice.Slice.Tools includes by default; before, it was silently ignored. Including one of these files again
  with `<SliceCompile Include="...">` is now a build error, like duplicate `Compile` items in the .NET SDK: use
  `Update` to set its metadata, or set `EnableDefaultSliceCompileItems` to `false` to list the files explicitly.
