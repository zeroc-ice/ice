- Fixed `<SliceCompile Update="...">` and `<SliceCompile Remove="...">` in C# project files: previously, they had no
  effect on the `.ice` files that ZeroC.Ice.Slice.Tools includes by default.
- Including one of these default `.ice` files again with `<SliceCompile Include="...">` is now a build error. Use
  `Update` to set the metadata of a default item, or set `EnableDefaultSliceCompileItems` to `false` to list your
  `.ice` files explicitly.
