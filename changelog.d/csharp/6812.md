- `slice2cs` now generates the `[Obsolete]` attribute on the proxy interface and proxy helper class of a deprecated
  Slice interface, and on the value of a deprecated Slice constant. Previously, C# code that used a deprecated
  interface or constant compiled without any warning.
- `slice2cs` no longer generates the `[Obsolete]` attribute on the skeleton methods of a deprecated Slice operation
  (or, in IceRPC mode, on the service interface of a deprecated Slice interface). Like the C++ and Java mappings, the
  C# skeletons never carry this attribute, so implementing a deprecated interface or operation does not warn.
