- `slice2cs` now generates the `[Obsolete]` attribute on:
  - the proxy interface and proxy helper class of a deprecated Slice interface (in Ice mode)
  - the value of a deprecated Slice constant
- `slice2cs` no longer generates the `[Obsolete]` attribute on:
  - the skeleton methods of a deprecated Slice operation (in Ice mode)
  - the service interface of a deprecated Slice interface (in IceRpc mode)
