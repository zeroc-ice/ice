- Fixed `slice2cpp_generate` in the Ice CMake package: when an `INCLUDE_DIRS` directory or a Slice file was reached
  through a symbolic link, the generated headers no longer matched the `#include` directives slice2cpp emits, and the
  build failed on a missing generated header. The mirrored layout now resolves symbolic links the way slice2cpp does.
- Fixed slice2cpp's include-path matching: an include directory that is a string prefix of a sibling directory, such
  as `-I /a/b` with a Slice file under `/a/bc`, no longer produces a mangled `#include` directive in the generated
  header.
