- Fixed a build failure of the OpenSSL-based IceSSL transport with OpenSSL 4.0 or later.

- With OpenSSL 4.1 or later, `IceSSL.CheckCertName` matches the target host only against the Subject Alternative
  Names of the server certificate. A connection to a server whose certificate identifies the host only through its
  Common Name now fails with a `SecurityException`; add a DNS or IP Subject Alternative Name to such certificates.
  This is a change in the OpenSSL default behavior; Ice built with earlier OpenSSL versions is not affected.
