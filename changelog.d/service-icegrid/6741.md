- Removed the `IceGrid.Registry.Trace.Topic`, `IceGrid.Registry.Trace.TopicManager` and
  `IceGrid.Registry.Trace.Subscriber` properties, which have had no effect since Ice 3.8.0. A registry configured with
  one of them now fails to start with an "unknown Ice property" error. To trace the IceStorm topic manager embedded
  in the registry, use `IceStorm.Trace.Topic`, `IceStorm.Trace.TopicManager` and `IceStorm.Trace.Subscriber`.
