- The `checkedCast` and `uncheckedCast` methods generated by `slice2php`, and those of `Ice\ObjectPrxHelper`, now
  return null when the source proxy is null, as in the other language mappings. For example, you can now cast the
  proxy returned by `Communicator::propertyToProxy` without first checking for null. Recompile your Slice files to
  get the new behavior in generated code.
